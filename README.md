# Fermentation

[![Открыть Fermentation в Marketplace Home Assistant](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=Edheltur&repository=ha-fermentation&category=integration)

Одна партия — одно устройство Home Assistant. Интеграция ведёт брожение по показаниям RAPT Pill, хранит ручные пробы и рассчитывает крепость и видимую степень сбраживания.

## Установка

Требуется **Home Assistant 2026.11 или новее**. Подключите Pill через штатную интеграцию **RAPT Bluetooth** и включите у него сенсор плотности SG.

Откройте Marketplace кнопкой выше или добавьте `Edheltur/ha-fermentation` через **Настройки → Marketplace → Добавить по ссылке**. Выберите **Fermentation → Установить**.

## Ведение партии

В **Настройки → Устройства и службы → Добавить интеграцию → Fermentation** выберите Pill и задайте название партии. Рабочий WCF нужен для OG по рефрактометру и для оценки крепости по двум оптическим отсчётам. Его можно исправить позже в настройках партии.

- **Начало брожения** включает наблюдение с момента внесения дрожжей. Один Pill можно использовать в последовательных партиях. Для параллельного брожения в разных баках выберите разные Pill.
- **Начальная и конечная пробы** принимают показания АС-3, температуру пробы, отсчёт рефрактометра и pH. Начальная плотность берётся по АС-3, при его отсутствии — по рефрактометру с поправкой WCF. Для конечной плотности нужен замер АС-3.
- **Дата розлива** завершает сбор. Итоги можно уточнить позднее, исправив замеры на странице устройства.

Для АС-3 введите отсчёт со шкалы и температуру самой пробы. Интеграция сохраняет исходный замер и приводит его к 20 °C перед расчётом плотности, WCF по OG и производных показателей. Для сусла и пива это приближение по [таблице 1 приложения 1 ГОСТ 6687.2-90](https://base.garant.ru/70240954/53f89421bbdaf741eb2d1ecc4ddb4c33/). Между узлами применяется линейная интерполяция по температуре и отсчёту.

Таблица охватывает 15–25 °C и отсчёты 5–25 %. За этими пределами измерьте пробу при 20 °C. При 20 °C принимается любой отсчёт прибора. Пока замер вне таблицы, конечная плотность по нему недоступна, а для начальной плотности возможен обычный расчёт по рефрактометру. Если вводите уже приведённое к 20 °C значение, оставьте температуру пустой.

Крепость по рефрактометру рассчитывается по двум отсчётам одного прибора: до внесения дрожжей и после окончания брожения. Оба делятся на рабочий WCF. Для конечной плотности применяется линейная [поправка Террилла](https://braureka.de/calculations/refractometer-correction/), затем крепость оценивается как 131,25 × (OG − FG).

Суточное изменение плотности сравнивает медианы двух получасовых окон с интервалом 24 часа. До накопления опорных точек значение недоступно. Для графиков используется Recorder. Чтобы хранить подробную историю месяц, задайте в его настройках `purge_keep_days: 30`.

## Отчёт

Откройте настройки записи ферментации и выберите **Отчёт**. Скопируйте текст из многострочного поля. Сводка строится из сохранённых дат и ручных проб.

## Дашборд

1. Установите [ApexCharts Card](https://github.com/RomRider/apexcharts-card) через HACS и убедитесь, что его JavaScript-модуль добавлен в ресурсы дашбордов.
2. В **Настройки → Панели → Ресурсы** добавьте `/api/fermentation/static/fermentation-card.js` как **JavaScript-модуль**. Для управления ресурсами включите расширенный режим в профиле HA.
3. Обновите страницу Home Assistant. В режиме редактирования панели выберите **Добавить карточку → Fermentation**.

Для ручного добавления используйте:

```yaml
type: custom:fermentation-card
```

Карточка сама находит партии. Для первого ввода даты используется диалог карточки. Заполненные даты и ручные пробы открываются в штатном окне сущности. График показывает записанную историю, а для более старых периодов использует часовые средние Recorder. Сбор данных, пробы и расчёты доступны без карточек.

## Разработка

В окружении с Python 3.14 установите зависимости из `requirements-dev.txt`. Запустите `ruff check .`, `ruff format --check .` и `python -m pytest`.

Для проверки подготовки данных графика в Node.js 22+ запустите `node --test tests/test_dashboard.mjs`.
