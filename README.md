# Fermentation

[![Открыть Fermentation в Marketplace Home Assistant](https://my.home-assistant.io/badges/marketplace_repository.svg)](https://my.home-assistant.io/redirect/marketplace_repository/?owner=Edheltur&repository=ha-fermentation&category=integration)

Одна партия — одно устройство Home Assistant. Интеграция ведёт брожение по показаниям RAPT Pill, хранит ручные пробы и рассчитывает крепость и видимую степень сбраживания.

## Установка

Требуется **Home Assistant 2026.11 или новее**. Подключите Pill через штатную интеграцию **RAPT Bluetooth** и включите у него сенсор плотности SG.

Откройте Marketplace кнопкой выше или добавьте `Edheltur/ha-fermentation` через **Настройки → Marketplace → Добавить по ссылке**. Выберите **Fermentation → Установить**.

## Ведение партии

В **Настройки → Устройства и службы → Добавить интеграцию → Fermentation** выберите Pill и задайте название партии. Для расчёта начальной плотности по рефрактометру укажите рабочий WCF. Его можно исправить позже в настройках партии.

- **Начало брожения** включает наблюдение с момента внесения дрожжей. Один Pill можно использовать в последовательных партиях. Для параллельного брожения в разных баках выберите разные Pill.
- **Начальная и конечная пробы** принимают показания АС-3, температуру пробы, отсчёт рефрактометра и pH. Начальная плотность берётся по АС-3, при его отсутствии — по рефрактометру с поправкой WCF. Для конечной плотности нужен замер АС-3.
- **Дата розлива** завершает сбор. Итоги можно уточнить позднее, исправив замеры на странице устройства. Чтобы возобновить наблюдение, очистите дату розлива действием `fermentation.clear_date`. Для удаления ошибочного замера используйте `fermentation.clear_reading`.

Суточное изменение плотности сравнивает медианы двух получасовых окон с интервалом 24 часа. До накопления опорных точек значение недоступно. Для графиков используется Recorder. Чтобы хранить подробную историю месяц, задайте в его настройках `purge_keep_days: 30`.

## Разработка

В окружении с Python 3.14 установите зависимости из `requirements-dev.txt`. Запустите `ruff check .`, `ruff format --check .` и `python -m pytest`.
